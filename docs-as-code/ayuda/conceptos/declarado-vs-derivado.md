# Valor declarado y valor derivado

El valor declarado es el número que tu programa escribió en el texto del trabajo. El valor derivado es el que el laboratorio calcula a partir de las dimensiones que vos mismo declaraste. El laboratorio muestra los dos y no corrige el tuyo: la diferencia es una señal para que revises tu programa.
