# Ortoedro

Un ortoedro es un cuerpo con caras rectangulares, donde cada cara se encuentra con sus vecinas en ángulo recto. Tiene tres dimensiones que pueden ser distintas: largo, ancho y altura. Cuando las tres son iguales, el ortoedro es un cubo.
