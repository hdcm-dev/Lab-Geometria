# Estado Pendiente

Pendiente es el estado de un trabajo que enviaste a revisión y que el docente todavía no aprobó ni rechazó. Mientras está pendiente ya no se edita. Cuando el docente lo resuelve, pasa a finalizado o a rechazado, a veces con un comentario.
