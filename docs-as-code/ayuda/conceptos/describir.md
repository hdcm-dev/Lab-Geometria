# El método Describir()

Describir() es el método de tus clases que arma el texto del trabajo. Lo escribís vos a propósito: el ejercicio es que tu programa respete los nombres de los atributos y la jerarquía de las figuras. El laboratorio lee ese texto y te muestra lo que entendió; la forma general del intercambio está en el ejemplo de la pantalla de carga.
