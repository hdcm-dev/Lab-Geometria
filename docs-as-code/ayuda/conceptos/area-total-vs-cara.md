# Área total y área de una cara

El área de una cara es la superficie de una sola de las caras del cuerpo. El área total es la superficie de toda la piel del cuerpo, todas sus caras juntas. Una forma de comprobarlo es mirar la figura en el visor y contar las caras que la forman.
