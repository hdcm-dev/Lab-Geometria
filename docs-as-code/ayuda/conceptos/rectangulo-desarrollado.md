# Rectángulo desarrollado

El rectángulo desarrollado es la superficie lateral del cilindro cuando se la desenrolla sobre un plano. En el laboratorio aparece sólo como componente del cilindro, no como figura suelta. Para entenderlo, pensá qué borde del rectángulo era antes la vuelta completa alrededor de la tapa.
