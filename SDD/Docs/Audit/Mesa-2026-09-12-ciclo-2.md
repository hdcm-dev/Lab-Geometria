## 2. Estado actual verificado

### 2.1 Autenticación / autorización
- `src/GeometriaFactory.Api/Composition/CompositionRoot.cs` arma JWT Bearer HS256, con `AccessTokenIssuer` y guardia de arranque si `AccessToken:SigningKey` falta o es corta.
- Modelo ROPC: el front intercambia usuario/contraseña por token en `POST /auth/token`; el token nunca llega al navegador. Documentado como decisión consciente en el intake §17.1.P.5, con la nota de que ROPC está desaconsejado por OAuth 2.1 y se acepta porque el intermediario es del mismo sistema.
- `curl -X POST https://api-geometria.aplicada.stream/auth/token -d '{"email":"x","password":"y"}'` → `HTTP 401` (RF-10).
- **Consecuencia para E-02:** un cliente externo real no puede usar ROPC sin manejar la contraseña del alumno, que es lo que OAuth 2.1 prohíbe para terceros.

### 2.2 CORS

## 3. El estándar de versionado, con fuentes, y la convención propuesta

### 3.1 Producto: SemVer 2.0.0 — sin cambios
Fuente: https://semver.org/spec/v2.0.0.html. Formato `vMAJOR.MINOR.PATCH`, sin prerelease.

### 3.2 Contrato REST — las prácticas de industria
| Práctica | Pros | Contras | Referencia |
|---|---|---|---|
| Versión en la ruta (`/v1/`) | Visible, cacheable, dos versiones en paralelo trivial | Invita a versionar el recurso entero | Convención dominante en REST público; Microsoft REST API Guidelines §12 la recomienda para servicios públicos: https://github.com/microsoft/api-guidelines/blob/vNext/azure/Guidelines.md#12-versioning |
| Cabecera (`Accept-Version`) | Ruta limpia | Invisible en logs y navegador | Suele combinarse con ruta |
| Media type (`application/vnd.x.v1+json`) | «Más REST» | Compleja de implementar y documentar | GitHub como mecanismo secundario |
| Fecha (`Stripe-Version: 2024-06-20`) | Cambios incrementales por cliente | Exige capa de traducción interna | https://stripe.com/blog/api-versioning |

### 3.3 Convención propuesta
**Versión en la ruta, `/v{MAJOR}/`, sólo el MAJOR**, compartido con el del producto (una sola cifra). Fundamento: extensión mínima de lo ya adoptado; operable sin herramienta extra por un equipo de un docente; resuelve `ADR-00008` derogando su regla 1 sólo para la superficie pública.
**Evento de etiqueta:** toda fusión a `main` que cambie código de producción recibe etiqueta SemVer calculada por Conventional Commits — no el cierre de etapa, que dejó 129 fusiones sin etiqueta.
**Herramienta:** MinVer (menor huella) o Nerdbank.GitVersioning; cierra `PA-06`.
**Deprecación:** al publicar `/v2/`, `/v1/` se mantiene un plazo mínimo (propuesta: un cuatrimestre) con cabecera `Deprecation` (https://datatracker.ietf.org/doc/html/draft-ietf-httpapi-deprecation-header).
